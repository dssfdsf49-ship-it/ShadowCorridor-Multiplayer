# 그림자 복도 2인 멀티 실험판 (비공식 MOD)

Steam 게임 「그림자 복도(影廊 -Shadow Corridor-)」의 「매미의 복도」를 **두 사람이 같이** 해 보는 **무료 비공식 MOD**입니다.
아직 실험판이라 게임이 꺼지거나 이상하게 보일 수 있습니다.

- 제작자(Space Onigiri Game)의 공식 제품이 아닙니다. 제작자의 답변에 따라 무료 MOD 배포는 허용되며 유료 판매는 허용되지 않습니다.
- 수정하지 않은 게임 원본 자료는 들어 있지 않습니다. 두 사람 모두 원작 게임이 설치되어 있어야 합니다.
- [그림자 복도 구역 랜더마이저](https://github.com/dssfdsf49-ship-it/ShadowCorridor-Randomizer)와는 따로 쓰는 MOD입니다. 둘을 동시에 쓸 수 없습니다.

## 지금 되는 것

| 항목 | 내용 |
|---|---|
| 스테이지 | 매미의 복도만 |
| 난이도 | 호스트가 도전자 또는 커스텀 모드로 시작 |
| 인원 | 방을 여는 사람(호스트) + 들어가는 사람 1명 |
| 같이 되는 것 | 서로의 모습(히바나), 괴물, 곡옥, 아이템 줍기와 쓰기, 문, 서랍, 촛불, 사물함, 골 |
| 칭호 | 각자 자기 타이틀 메뉴에서 고름(첫 판을 시작하기 전에) |
| 화면 표시 | 게임 화면 왼쪽 위에 상대의 상태와 체력(「상대: 생존 · HP 80」 / 사망), 타이틀에 방 상태(방 열림 / 1명 들어옴 / 접속됨) |
| 빠른 신호 | 숫자 키 1 「이쪽!」 · 2 「도망쳐!」 · 3 「기다려」 — 상대 화면에 3초 동안 글이 뜨고, 보낸 사람 자리에서 소리가 남 |
| 빛나는 붓 | 바닥에 그린 낙서가 상대 화면에도 같은 자리·같은 무늬로 보임(다음 판에서 지워짐) |
| 곡옥 소리 | 한 사람이 곡옥을 주우면 상대에게도 줍는 소리가 들림 |
| 죽었을 때 | 상대 화면을 지켜봄(관전) — 그 사람의 경과 시간·곡옥 수·아이템과 개수가 보이고 위아래 시점도 따라감. 둘 다 죽으면 호스트에게 「다시 하기 / 타이틀로」 |
| 관전 그만두기 | 호스트는 관전 중 Esc를 눌렀다 떼면 「다시 하기 / 타이틀로」(그 판을 끝냄). 들어간 사람이 타이틀로 나가면 5초쯤 뒤 호스트 관전이 저절로 풀림 |
| 방 관리 | 참가 암호, 한 번에 1명, 내보내기 |

## 받기

[Releases](https://github.com/dssfdsf49-ship-it/ShadowCorridor-Multiplayer/releases)에서 최신 zip을 받아 아무 폴더에나 모두 풉니다.
자세한 순서는 zip 안의 「읽어 주세요.txt」에 있습니다.
새 판이 나오면 zip을 다시 받아 새 폴더에 풀고 「1 실험 Pak 넣기」를 누르면 새 판으로 바뀝니다(옛 폴더는 지워도 됩니다).

필요한 것: Windows 10·11, Steam판 그림자 복도. 랜더마이저 앱이나 다른 프로그램은 필요 없습니다.
두 사람이 **같은 판의 zip**을 써야 합니다(「1 실험 Pak 넣기」 화면에 나오는 판 글자가 같아야 함).

## 순서

| | 방을 여는 사람 (호스트) | 들어가는 사람 |
|---|---|---|
| 처음 한 번 | 0 → 1 | 0 → 1 |
| 할 때마다 | 2(암호 정하기) → 게임 켜기 → 타이틀의 「부가 메뉴」 줄 뒤에 「[멀티: 방 열림]」 | 3(주소·암호 입력) → 게임 켜기 → 타이틀의 「부가 메뉴」 줄 뒤에 「[멀티: 접속됨]」 |
| 시작 | 「매미의 복도」를 시작 | 시작 화면에서 아무 키 |
| 끝나면 | 9 | 9 |

- 호스트가 먼저 게임을 켜서 「[멀티: 방 열림]」이 보인 뒤에 상대가 게임을 켭니다. 상대가 들어와 암호 확인이 끝나면 호스트 쪽 표시가 「[멀티: 1명 들어옴]」으로 바뀝니다.
- 들어가는 사람은 기다리는 동안 「메인 게임」에서 칭호를 골라 둘 수 있습니다(스테이지 시작은 호스트만 할 수 있습니다).
- 게임을 껐다 켤 때마다 2번(호스트)·3번(접속)을 다시 눌러야 합니다.
- 끝나면 9번을 눌러 게임을 원래 상태로 돌려 주세요. 실험 Pak이 들어 있는 동안에는 혼자 하는 게임을 하지 말아 주세요.

## 연결

이 게임에는 방 목록이나 친구 초대가 없어서, 들어가는 사람이 호스트 PC의 주소를 직접 입력합니다. 게임이 쓰는 문은 UDP 7777번입니다.

- 같은 집(같은 공유기): 호스트 PC의 집 안 주소(192.168.…)를 씁니다.
- 다른 집: 아래 둘 중 하나가 필요합니다.
  - 가상 랜 프로그램: 두 사람이 같은 프로그램으로 같은 방에 들어간 뒤, 그 프로그램이 보여 주는 호스트의 주소를 씁니다.
  - 공유기 포트 열기(포트 포워딩): 호스트 집 공유기에서 UDP 7777번을 호스트 PC로 넘기고, 호스트 집의 인터넷 주소를 씁니다.

## 보안 — 하기 전에 꼭 읽어 주세요

이 실험판은 두 사람의 게임이 인터넷으로 직접 연결됩니다. **아는 사람, 믿을 수 있는 사람과만** 해 주세요.

방을 여는 사람

- 주소와 참가 암호는 들어올 사람에게만 알려 주세요. 방송 화면이나 채팅에 띄우지 마세요. 집 인터넷 주소가 널리 알려지면 접속 방해(디도스)를 받을 수 있습니다.
- 공유기에서 문을 열 때는 UDP 7777번 하나만 엽니다. 「DMZ」나 「전체 열기」는 쓰지 말고, 끝나면 그 규칙을 지워 주세요.
- 게임을 「관리자 권한으로 실행」하지 마세요.
- 참가 암호는 모르는 사람이 게임에 끼어드는 것을 막아 줍니다. 게임 자체에 알려지지 않은 허점이 있을 경우까지 막아 주지는 못합니다(그런 사례를 찾지는 못했지만 없다고 장담할 수 없습니다). 그래서 주소를 아무에게나 알려 주면 안 됩니다.
- 들어온 사람의 게임이 보내는 값(위치·문·아이템)은 대부분 그대로 받아들입니다. 장난을 완전히 막지는 못하니, 이상하면 「4 호스트 - 내보내기」를 누르세요.

들어가는 사람

- 믿을 수 있는 사람이 연 방에만 들어가세요. 들어가는 쪽의 게임도 호스트의 게임과 직접 연결됩니다.

두 사람 모두

- 연결된 두 PC는 서로의 인터넷 주소를 알 수 있고, PC 이름이 상대 게임에 전해질 수 있습니다(화면에는 나오지 않습니다).
- 이 zip은 이 저장소의 Releases에서 받은 것만 쓰세요. 다른 사람이 고쳐서 다시 올린 것은 실행하지 마세요.
- zip 안의 파일이 하는 일은 셋뿐입니다.
  - 게임 Paks 폴더에 파일 하나를 넣고 빼기
  - 게임 세이브 폴더에 작은 명령 파일을 쓰고 지우기(게임 세이브 자체는 건드리지 않음)
  - (호스트만) 게임 설정 파일 Game.ini에 두 줄을 넣고 빼기
- 인터넷으로 아무것도 보내지 않고, 다른 프로그램을 받아 오거나 실행하지 않습니다. `tools` 폴더의 `multi.ps1`을 메모장으로 열면 직접 확인할 수 있습니다.

## 확인된 것과 아직 확인하지 못한 것 (2026-11-15)

- 확인된 것(한 PC에서 게임 두 개를 켜서): 매미의 복도 한 판을 골까지, 타이틀의 방 상태 표시, 들어가는 사람의 칭호 고르기, 상대 상태와 체력 표시, 빠른 신호,
  상대의 달리기 발소리가 멀수록 작아지는 것, 빛나는 붓 낙서, 곡옥 소리, 관전 화면(시간·곡옥·아이템·개수·위아래 시점), 관전 중 Esc, 들어간 사람이 타이틀로 나갈 때.
- 서로 다른 PC(다른 집) 사이의 접속과 플레이도 확인했습니다(v48).
- 아직 확인하지 못한 것:
  - 판 도중에 한 사람이 게임을 꺼 버렸을 때
  - 틀린 암호로 들어온 사람을 돌려보내기, 내보내기
  - 서랍·철제 상자 문의 일부
- 관전 중 체력·스태미나 막대는 실제와 다를 수 있습니다(상태 줄의 HP가 맞는 값).
- 문제가 생기면 게임을 끄고 「9 실험 끝 - Pak 빼기」를 누르면 원래대로 돌아갑니다.

## 알아 둘 것

- 랜더마이저 앱을 쓰시는 분은 앱에서 「원본 맵으로 복원」을 한 뒤에 쓰세요. 실험 Pak이 들어 있는 동안에는 앱의 적용·복원이 멈춥니다.
- 서로의 화면이 조금씩 다르게 보일 수 있습니다(상대나 괴물의 위치가 인터넷 지연만큼 늦게 보입니다).
- 영상·방송·다른 곳에 올리는 것은 자유이지만, 비공식 MOD임을 표시하고 무료로만 배포해 주세요.
- 이 MOD 때문에 생긴 문제를 원작 제작자에게 문의하지 말아 주세요.
